How recommendations work

Test now: documented access and a concrete workflow fit justify a bounded sandbox evaluation. Watch: potential value, with unresolved evidence, cost or deployment constraints. Low priority: limited relevance to the current workflow goals.

Reviews distinguish publisher claims, independent evidence and hands-on tests. Unknown costs and unmeasured performance remain unknown. Unreviewed records are not automatically classified as low priority. Source release rows are preserved separately.

Priority workflows: agent automation, API integration, document processing, coding, real-time monitoring and research. No paid calls, production changes or private-data tests are performed by these reviews.
